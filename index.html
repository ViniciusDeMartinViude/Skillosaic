AI inside Skillosaic

From camera pixels to a physical paint recipe

Skillosaic combines unsupervised clustering, calibrated regression models and numerical optimization. The goal is not only to identify representative colors, but to translate what the camera sees into a LAB target that can be reproduced with Red, Yellow and Blue paint.

01
Unsupervised learning

K-Means color clustering

K-Means reduces thousands of image pixels to a small number of representative color groups. It does not need labeled examples; it discovers groups by measuring similarity between colors.

Mosaic & Contours tab

  • Pixels are converted from sRGB to CIELAB.
  • Black and white are separated first using the L* thresholds.
  • K-Means++ groups the remaining pixels using the a* and b* color channels.
  • The current mosaic uses five color clusters, plus the black and white groups.

Paint Formulation tab

  • The user can select K from 3 to 10.
  • Clustering uses the full L*, a*, b* coordinates.
  • The clusters are ordered by image coverage and become the representative-color cards.
Pixel LAB → nearest centroid → representative color
02
Supervised calibration model

Camera LAB correction

A webcam is not a calibrated colorimeter. Its sensor, lighting, white balance and browser processing can shift the LAB values. Skillosaic therefore learns how the camera differs from the Nix measurements used as the physical reference.

Input Camera LAB
→
Learned target ΔLAB = Nix LAB − Camera LAB
→
Output Nix-equivalent LAB
  • The calibration set contains paired Camera LAB and Nix LAB measurements.
  • Camera LAB is standardized before prediction.
  • A cubic Radial Basis Function (RBF) regression model predicts the LAB correction.
  • The current camera model uses smoothing = 5.0.
Corrected LAB = Camera LAB + RBF(Camera LAB)

Manual LAB values entered from Nix or another calibrated source bypass this camera-correction step.

03
Regression + optimization

Paint formulation model

The paint model learns the relationship between known Red / Yellow / Blue mixtures and the LAB values physically measured with the Nix device.

24 measured recipes R% · Y% · B%
→
Cubic RBF Forward paint model
→
Predicted LAB for any candidate recipe
  • The forward model uses Red and Yellow as independent coordinates.
  • Blue is constrained by B = 100 − R − Y, so the recipe always totals 100%.
  • The current paint RBF uses smoothing = 0.001.
  • CIEDE2000 (ΔE00) measures how close each predicted paint color is to the target LAB.

How the inverse recipe is found

The application does not rely on a direct inverse neural network. It uses the learned forward model and searches the valid R/Y/B mixture space for the recipe with the smallest ΔE00.

  1. If a measured recipe is already within ΔE00 ≤ 1.0, that physical measurement is reused.
  2. Otherwise the whole R/Y/B simplex is searched in 1% steps.
  3. The best area is refined locally in 0.25 percentage-point steps.
  4. The selected percentages are converted to grams using the requested total paint mass.
Best recipe = arg min ΔE00(Target LAB, Predicted LAB(recipe))
What is AI here?

Three different kinds of intelligence work together

Skillosaic does not use a large neural network. It combines interpretable machine-learning methods with color science and constrained numerical search.

How it works

  1. 1
    Upload an image

    Drop or select any photo. It is read entirely in your browser — nothing is uploaded to a server.

  2. 2
    Convert to LAB colour space

    Each pixel is converted from sRGB → XYZ → L*a*b*. LAB separates lightness (L) from colour information (a, b), making clustering perceptually uniform.

  3. 3
    Isolate black & white

    Pixels with L below the Black threshold or above the White threshold are pre-assigned to dedicated clusters before clustering begins.

  4. 4
    K-Means on a & b channels

    The remaining pixels are clustered using K-Means++ (K = 5) applied only to the a and b channels. Lightness is intentionally ignored so colour grouping is independent of brightness.

  5. 5
    Reconstruct the mosaic

    Each pixel keeps its original L value but its a and b are replaced by its cluster centroid. The result is converted back to sRGB and displayed.

  6. 6
    Palette, contours & smoothing

    Click palette swatches to isolate specific colour groups. Toggle Contours to see only cluster boundaries. Use the Smoothing slider to merge small regions via a mode filter.
